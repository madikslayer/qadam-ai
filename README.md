# qadam-ai
Qadam AI — онлайн-сервис, который помогает малому бизнесу автоматизировать создание контента и продвижение в социальных сетях с помощью искусственного интеллекта.  Сервис помогает предпринимателям создавать идеи для публикаций, рекламные тексты, описания товаров и контент-планы, экономя время и упрощая продвижение бизнеса.
